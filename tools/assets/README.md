# Varlık üretim betikleri

Gereksinimler: `python -m pip install numpy pillow lameenc`

Proje kökünden çalıştırın:

    python tools/assets/make_sounds.py assets/sounds
    python tools/assets/make_boards.py assets/boards

Taş takımları dışarıdan alınmıştır, üretilmez; kaynakları ve lisansları
için `ASSETS.md` dosyasına bakın.

Üretim yinelenebilirdir: rastgelelik sabit tohumlarla beslendiği için
aynı betik her çalıştırmada aynı dosyaları verir.

Ayrıntılı açıklama için depo kökündeki `ASSETS.md` dosyasına bakın.
